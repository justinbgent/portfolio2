Rekor Blue

Completed 2022

Role

Android Developer

Tooling

Kotlin, Github, Room, Retrofit, Coroutines, REST

Platforms

Android, iOS

Rekor Blue, scans license plates with precision. It was built to quickly capture frames, piping them to a License Plate Recognition library for fast processing. The plate numbers were compared against hotlists and if a match was found, the user was notified. This was paired with a local database and a REST API for user authentication, managing configuration files, and storing data from scanning sessions.
